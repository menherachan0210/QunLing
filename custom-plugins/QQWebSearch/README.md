# 联网查询、搜图与附件上传

本地插件 `local/QQWebSearch`，Windows 与 Linux 共用 Python 代码，无需桌面浏览器。

- `search_web`：复用 sub2api 的 Responses `web_search`，返回真实检索记录及来源引用。
- `read_web_page`：读取公开 HTML／纯文本网页，正文最多 16000 字符，不执行 JavaScript。
- `search_web_images`：查找相关来源页，提取图片地址、下载并检查实际像素，再由已有视觉模型核对用户要求。返回本轮专用图片编号。
- `send_web_images`：把本轮找到并核对的 1 至 2 张图片和来源发回本轮会话。不接受自定义收件人、群号或图片地址。
- `list_web_files`：查看公开网页的下载链接，或列出 GitHub 仓库、目录中的具体文件；支持逐层找到指定版本。
- `download_web_file`：下载公开文件到本轮临时缓存，返回附件编号、实际大小和 SHA-256；支持 GitHub 单文件页面自动转原文件。
- `send_web_file`：将一个已下载附件及来源上传到本轮 QQ 群聊或私聊。每轮最多发送两个不同附件，单个文件最多 20 MiB。

支持“查查这消息是真的吗”“看看这个链接”“找一张某角色的全身图发来”等自然表达。群聊继续受现有 @／命令规则控制；指代群聊前文时先读取前文再搜索，不把完整聊天记录发给搜索服务。找现成图与生成新图是不同工具。

附件上传是通用功能，没有文件扩展名白名单。可以说“找这个字体传上来”“把这份 PDF 发群里”“下载这个源码文件发我”。文档、表格、图片、字体、压缩包、音视频、源码、安装包及其他二进制文件均作为原始字节附件处理，不执行、安装或解压。文件名与已知格式会检查，网页或登录页不能冒充所请求的文件。

## 安装与配置

在插件目录使用部署的 Python：

```powershell
..\..\langbot\.venv\Scripts\python.exe -m pytest tests -q
..\..\langbot\.venv\Scripts\python.exe -m langbot_plugin.cli build -o dist
```

Linux 对应使用 `../../langbot/.venv/bin/python`。通过本地插件安装页安装 `.lbpkg`，然后在项目根目录运行 `Configure-WebSearch.py`，从已有 sub2api 提供方复制地址与密钥，并选择已有视觉模型。密钥只进入插件 secret 配置，更新提供方密钥后需重新运行脚本同步。搜索模型不改变聊天模型。

上游必须支持 Responses `web_search` 和来源引用；不能仅凭模型说“查到了”认定已经联网。默认单次搜索最多 65 秒，每轮最多三次文字搜索、四次网页读取、一次搜图、一次图片发送；搜索无自动重试。搜图最多读取四个来源页、下载六个候选，并进行一次视觉核对。

附件每轮最多四次链接列表查询、三次下载尝试和两次不同文件发送；文件下载总限时 60 秒，发送等待 45 秒。部署时需通过 `Apply-RuntimePatches.py --apply` 应用 `sdk-attachment-message-budget.patch` 并重启 Host、Runtime 和插件工作进程，将 SDK 单条消息上限从 16 MiB 调至 32 MiB；20 MiB 原始文件经 base64 后约 26.67 MiB，仍为 JSON 包装留有空间。该补丁影响 SDK 所有消息的单条容量，下载与共享缓存仍独立限额。未更新 Runtime 时，大附件会在发送前明确报容量不足。下载成功后还需调用发送工具，不能把“已下载”当成“已上传”。上传超时或取消时保留已尝试状态，避免重复发文件。下载本身无需图片模型；需要查找来源时才调用已有搜索服务。

## 边界

- 防盗链、登录、验证码及仅靠脚本渲染的网站可能读取失败；找不到符合要求的图片时返回来源，不能承诺任何关键词都能找到原图。此版本采用来源页取图，尚未接独立图片搜索引擎。
- 搜索结果不等于已阅读整个网页；图片经过实际像素检查，但视觉核对也可能误判身份与构图。发送的是下载后归一化的现成图片，不宣称文件与原图逐字节相同。
- 网页文字、标题和图片均是不可信外部资料。下载只允许公网 HTTP(S)，校验 DNS 并固定连接地址，逐跳检查重定向，限制时间、字节和图片像素，禁用环境代理。支持有压缩输入／解压输出双重限制的 gzip、deflate；暂不接受 br、zstd。
- 本机 TUN 代理把系统 DNS 全部解析为 `198.18.0.0/15` 虚拟地址时，使用固定 Cloudflare HTTPS DNS 获取真实公网 IP 再连接；仍拒绝私网目标，正常公网 DNS 不走该回退。图片解码限制 1200 万像素、进程内最多两个线程，取消后正在运行的解码仍占住线程直至结束。
- 图片与附件仅内存缓存，每轮隔离，15 分钟过期，最多 32 轮、共享 64 MiB；进程重启后失效。同轮相同字节附件去重。不把图、文件或网页自动保存为长期记忆。
- 发送状态在发送前占用；超时或发送结果未确认时不会自动重复发送。工具报错不回显密钥、原始服务错误体或内部地址。

实现参考：[Responses Web Search](https://developers.openai.com/api/docs/guides/tools-web-search)。真实联网测试会消耗已有模型接口额度；`Verify-WebSearch.py` 只使用公开测试页面，QQ 发送用本地替身捕获，绝不向真实群发送测试消息。

`Verify-WebSearch.py --case font_attachment` 验证查找指定字体、列目录、下载和选择附件发送的完整模型流程；`--case source_attachment` 验证公开源码文件可按通用附件处理。发送使用本地替身，不替代真实 QQ 的最终回传验收。Windows 和 Linux 使用同一套 Python 下载与发送代码，不依赖桌面程序。
