# QQ 群聊前文与图片理解

让机器人在被 @ 或命令触发后，按需要阅读当前群提问者自己及其他成员刚才的讨论，再自然接话。无需固定措辞，例如“他们说的几部漫画你觉得哪个好”“我刚才那个方案靠谱吗”“上面两张图分别讲什么”。

0.1.1 补强了依赖前文的自然追问：本轮省略做法或背景时，像“我这样做对吗”“那怎么办”“你怎么看”这样的提问，应先读取提问者自己及其他成员的相关前文，再决定是否需要澄清。口语错字只有在已读语境支持唯一合理意思时才顺着理解；材料不足或多个指代都合理时仍须询问。这是模型工具选择提示，不是关键词规则，也不会让普通群消息主动读取历史。

0.1.2 修复 TUN 代理仅返回 fake-IP 时的图片解析失败。媒体读取错误返回固定 `stage`、`code`、`failed_refs` 和 `retryable`，不暴露下载地址。下载失败尚未调用视觉模型，可以按 `retryable` 再尝试一次；本轮总计最多两次读取、一次视觉模型调用，并发重复调用被拒绝。模型调用开始后，无论失败、超时或取消都不允许重试，避免重复计费。

0.1.3 统一按“回答需要什么证据”选择工具。结论依赖尚未看过的画面时，先取视觉证据；不要求用户说“看图”，也不把普通陈述一律当玩笑。文字已经足够时不强制看图。视觉子任务同时收到本轮问题、选中图片和相关发言，降低只看图片却不知道正在评价哪句话的信息损失；不新增模型自审或额外视觉轮次。

## 工作方式

`read_recent_group_context` 按当前可信群号和提问消息的位置读取最多 100 条、过去 60 分钟的群聊。主模型得到文字、说话人代号、显示名、当前提问者标记、相对时间、回复关系和图片编号；不把 QQ 号或图片下载签名 URL 交给模型。

`read_group_context_images` 只接受本轮已返回的图片编号，读取 1–4 张图交给配置的视觉模型。可用 `message_refs` 指定本轮已展示的最多 8 条原话，工具会保留发言者关系，把原文与分析问题一起交给视觉模型，并补充有限的图片原消息、回复和邻近语境。邻近只表示时间关系，不代表一定相关；子任务须区分看见的事实、解释和歧义。背景最多 12 条、正文合计 6,000 字符，截断明确标记。可识字、翻译、比较或解释现有图片；不是改图或生成图片工具。先前单人改图缓存是否存在，不影响本功能。

群聊前文和图片内文字都是资料，不作为指令执行。只读文字不会额外调用视觉模型；普通未触发消息不读取历史、不调用模型、不主动回复。本轮最多一次视觉分析，不自动重试。超过范围、平台没有记录、图片过期或指代不明时明确说明，不能假装看到完整群历史。更新后的 Host 群历史桥也可提供作为群文件上传的 PNG、JPEG、WEBP、GIF、BMP 图片；不可读取的图片附件会显示 `unavailable_images` 和数量提示，不能将剩余图片误当作完整参考图。

## 安装与跨平台

需要项目的 `patches/onebot-group-context.patch`，由 `Apply-RuntimePatches.py` 检查或应用到 LangBot 4.11.0，然后重启 LangBot。使用原有 NapCat 只读群历史接口，无需开启额外 QQ HTTP 服务。

用当前系统 Python 打包此插件，在管理页本地安装，运行根目录 `Configure-GroupContext.py` 选择已配置视觉模型。迁移时保留现有插件配置；业务代码可用于 Windows/Linux。

```sh
# 在本目录；Windows 用对应 .venv/Scripts/python.exe
../../langbot/.venv/bin/python -m langbot_plugin.cli build -o dist
```

查询锚点按安装、查询、机器人、群和提问者核对；模型不能指定群号、消息 ID、文件路径或 URL。文本总量最多 16,000 字符，每条最多 1,000；截断会标明。查询快照仅在内存保留 15 分钟，最多 16 个完整快照、每份 1 MiB。消息锚点最多 256 个，优先淘汰未触发消息；只有通过触发检查的本轮问题才额外保留最多 1,500 字符纯文字，不缓存普通群消息正文或引用正文。图片下载单张最多 10 MiB，40M 像素，转为最长边 2400 的 JPEG，单张 data URI 最多 2 MiB。只访问经 DNS 核验的公网 HTTP(S) 地址，逐跳检查重定向，不带服务密钥或 Cookie。

`pkg/public_network.py` 独立封装 DNS 策略：仅当系统返回的全部地址都属于 `198.18.0.0/15` 时，向固定 HTTPS 端点 `https://1.1.1.1/dns-query` 发起 DNS 查询，验证 TLS、问题、答案类型及公网地址，并直接连接验证后的 IP。不会直接连接 fake-IP；混合公网/私网、环回和其它非公网结果仍被拒绝。DNS 请求最多 5 秒、64 KiB，不跟随重定向，也不发送 Cookie 或服务密钥；只传域名及 DNS 记录类型，不传图片路径和签名参数。整个图片下载仍受原 20 秒上限约束。

历史只读取当前群；不读取私聊或其他群。不是永久群聊记忆；超过时间/消息范围需要引用或补充相关前文。合并转发、语音和非图片文件正文不在本次历史解析范围中，原有 TXT 与漫画压缩包工具仍独立使用。

## 验证

`tests/` 覆盖会话隔离、并发快照、提问者识别、多图分析、下载与计费去重、失败图片提示、媒体边界，以及纯 fake-IP 的受限 DoH 回退和混合私网拒绝；也用虚构自然追问验证 SDK 事件、工具描述、查询锚点与前文读取链路。运行不联网、不发送 QQ，不以模拟工具调用冒充真实模型选择效果。

根目录 `Verify-GroupContext.py` 使用虚构多人讨论与合成图片调用真实模型，验证自由表达能选择相应工具；平台历史接口使用替身，不发送 QQ 消息，会消耗模型额度。真实群聊效果仍需在 QQ 中验证。
